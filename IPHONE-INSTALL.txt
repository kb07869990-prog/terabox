VIDEO LINK HELPER — iPhone par “install” (Home Screen)

========================================
1) App Store jaisa .ipa install?
   - Yeh ZIP mein web app hai, App Store app NAHIN.
   - Asli iOS app banane ke liye Apple Developer ($), Xcode, signing — yeh project woh deliver NAHI karta.

2) Sab se qareeb hal: Safari → Home Screen par icon
   - iOS par “Add to Home Screen” ke liye page ko HTTPS par host karna BEHTAR hai
     (GitHub Pages, Netlify Drop, Cloudflare Pages — free).

   GitHub Pages (short):
   a) GitHub par naya repo banao (public).
   b) Is "iphone-pack" folder ki files repo ke root mein daal do
      (index.html, manifest.webmanifest, apple-touch-icon.png, yeh file).
   c) Repo Settings → Pages → Branch "main" / folder "/ (root)" → Save.
   d) 1–2 minute baad URL milega jaise:
      https://YOURNAME.github.io/REPO-NAME/
   e) iPhone Safari mein woh URL kholo.
   f) Share button → "Add to Home Screen" → naam de kar Add.

3) Sirf ZIP bina hosting?
   - Files app se index.html Safari mein khol sakte ho — kaam chal sakta hai,
     lekin "Add to Home Screen" / manifest har case mein poora support NAHI karta.
   - Behtar: upar wala HTTPS step.

4) Chrome extension?
   - Woh sirf desktop Chrome par. iPhone par woh install NAHI hota.
