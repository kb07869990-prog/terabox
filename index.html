Video Link Helper

Yeh web app hai — iPhone par Safari se chalti hai. Chrome extension jaisa har site auto-scan iOS par mumkin nahin.

Agar play na ho: CORS / hotlink block ho sakta hai — “Nayi tab” try karein, ya link PC par Chrome extension se nikaal kar paste karein.

Home screen par icon (install jaisa)

  1. Is folder ko HTTPS par host karein (GitHub Pages / Netlify — steps IPHONE-INSTALL.txt mein).
  2. iPhone Safari mein woh https link kholein.
  3. Share → Add to Home Screen → Add.

Sirf ZIP/Files se kholo to bhi page chal sakti hai, lekin Home Screen feature poora support har case mein nahin.
